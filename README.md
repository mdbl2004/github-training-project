## 📋 وصف المشروع
موقع ويب شخصي (Portfolio) متكامل ومتجاوب (Responsive)، تم بناؤه خصيصاً كواجب أول للتدريب الميداني. يهدف المشروع إلى تطبيق الممارسات العالمية في إدارة المشاريع البرمجية باستخدام أدوات **Git** و **GitHub**، وتنظيم خط سير العمل من خلال الفروع (Branches) وإدارة المهام (Issues).

---

## 🛠️ التقنيات المستخدمة
* **HTML5:** لبناء الهيكل الأساسي للصفحة (Navbar, Hero Section, Footer).
* **CSS3:** لتصميم وتنسيق الواجهة وإضافة الحركات التفاعلية وضمان التجاوب مع الشاشات المختلفة.
* **Git & GitHub:** لإصدار النسخ والمستودعات والتحكم بها.
